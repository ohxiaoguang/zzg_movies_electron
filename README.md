# Local Film Library · 本地影库

**简体中文** | [English](README.en.md)

把本地视频整理成自己的影库，标记值得重看的精彩片段，再用共鸣球把不同视频的精彩时刻放到同一屏幕。

Local Film Library 是面向 Windows 的本地影片管理与播放应用。它读取已有视频、NFO 资料、海报、剧照和评论截图，提供分类、收藏、搜索、播放与整理数据备份。日常使用以本地文件为主，局域网访问和 GitHub 云备份可按需开启。

[下载发行版](https://github.com/ohxiaoguang/zzg_movies_electron/releases) · [反馈问题](https://github.com/ohxiaoguang/zzg_movies_electron/issues) · [GPL v3 开源协议](LICENSE)

## 快速开始

1. 从发行版页面下载 Windows 安装程序或 ZIP 版本，安装或解压后启动。
2. 首次启动设置账号与密码；之后打开应用需要登录，可选择记住账号。
3. 在“来源管理”中添加视频文件夹，按需设置递归扫描，然后扫描来源。
4. 在“全部影片”浏览导入结果，为影片添加“我的分类”或收藏。
5. 打开详情播放视频，用 `I` / `O` 标记精彩片段；遇到想与其他视频一起重看的位置，点击“添加进共鸣球”。

## 特色功能：精彩片段

精彩片段为视频中值得重看的部分记录起止时间和标题。标注保存在影库中，不会裁剪、修改原视频或改写 NFO。

### 边看边标记

- 在详情的“片段标注”页，播放到目标位置后按 `I` 设置起点、按 `O` 设置终点，也可点击对应按钮。
- 填写片段标题，例如“精彩追逐戏”，选择是否“纳入精彩预览”，然后添加片段。每条标注对应具体视频文件，多段影片的标注也分别绑定到各段文件。
- 列表显示片段标题、时长和预览开关，可以删除不需要的标注，或调整是否参与预览。
- 标注 VR 视频时还会记录当前视角，点击片段播放时可以回到该视角。
- 原视频发生变化后，相关标注会提示检查时间点，方便确认原有范围是否仍然准确。

### 从时间轴快速重看

- 详情播放器的时间轴展示当前文件的片段分布，悬停可查看标题与起止时间。
- 点击时间轴按点击位置跳转；点击片段列表则从该片段起点播放。
- 详情中的片段用于定位原片，播放到片段终点后会继续播放原视频。
- 空格控制播放与暂停，左右方向键快退与快进；按住 `Shift` 使用微调步进。两种步进都可以在设置中调整。

### 在卡片上预览精彩内容

- 鼠标悬停影片卡片后出现横向预览窗，依次播放勾选了“纳入精彩预览”的片段，并循环预览。
- 视频预览默认静音，适合浏览影库时快速回忆内容。
- 预览窗可切换“精彩片段 / 评论 / 剧照”，图片以轮播方式浏览。
- 没有可用精彩片段时优先展示评论截图，再回退到剧照；视频无法播放时也会回退到图片。
- 可调整预览出现延迟、关闭延迟和图片轮播间隔。

## 特色功能：共鸣球

共鸣球把不同视频放到同一个多画面播放界面，让你将几部影片中喜欢的时刻组合起来重看。每个视频保留独立的位置，整组视频可以保存为场景。

### 收集与同屏播放

1. 打开任意影片详情，选择视频文件并定位到想保留的位置。
2. 点击“添加进共鸣球”。当前位置会记录为该视频的“精彩时刻”，详情播放器随即暂停；VR 视频同时带入当前视角。
3. 继续从其他影片添加视频，再点击左下角共鸣球进入多画面界面，球上显示当前视频数量。

- 多个视频按各自画面比例自动排布，保留独立播放进度。
- 支持“全部播放 / 全部暂停”，也可分别控制每个视频的播放、暂停和进度。
- 当前场景中的同一视频再次添加时，会更新其播放位置和精彩时刻。
- **回到精彩时刻**：让所有视频分别回到各自保存的位置，保持原来的播放或暂停状态。
- **更新全部精彩时刻**：用各个视频的当前进度覆盖当前场景中保存的精彩时刻，方便重新安排这组画面的起点。
- 可单独移除视频；“清空”需要再次点击确认，只清空当前场景。关闭共鸣球会暂停视频并保留位置。

**精彩片段与精彩时刻的区别：**精彩片段是影片中的时间范围，用于标注、跳转和悬浮预览；共鸣球的精彩时刻是某个场景里一个视频的时间点，用于让一组视频回到各自喜欢的位置。

### 保存多套共鸣场景

| 操作 | 使用效果 |
| --- | --- |
| 临时场景 | 没有命名的组合也会保留，方便随时收集视频。 |
| 新建场景 | 命名后切换到空白场景，原场景的组合与位置仍保留；随后从详情添加新视频。 |
| 保存为场景 / 另存为新场景 | 把当前组合保存为新的命名场景，并切换过去。 |
| 切换场景 | 保存并暂停当前组合，恢复目标场景的位置，等待开始播放。 |
| 管理场景 | 重命名、复制和删除；副本与原场景独立，删除当前场景会返回临时场景。 |
| 自动保存 | 每套场景独立保留视频列表及顺序、播放位置、精彩时刻、画面比例和 VR 视角，重启后恢复上次选择的场景。 |

日常调整会保存到当前场景。想保留原组合再尝试另一组视频时，先新建或另存为新场景。移除视频、清空或删除场景都不会删除原文件。共鸣球目前仅在桌面客户端提供。

## 影片浏览与分类整理

- **卡片与表格**：切换海报网格和列表，调整卡片宽度与每页数量；缺少海报时尝试自动生成视频封面。
- **整理视图**：提供全部影片、未整理、已整理、收藏和所有数据。“未整理”表示没有自定义分类，“已整理”表示至少有一个分类。
- **我的分类**：创建、重命名、排序和删除，一部影片可加入多个分类。删除分类不影响原文件、收藏或 NFO 标签。
- **收藏与资料编辑**：收藏和分类修改自动保存；详情中可编辑标题、原始标题、评分和备注。
- **全局筛选**：来源多选满足任一所选来源，分类多选同时包含全部所选分类。跨影片页面保留，重启或刷新后恢复，并可一键清空。
- **页面筛选与排序**：支持搜索、NFO 标签和演员筛选，以及标题、年份、评分、文件名、文件大小、最近新增、最近观看等排序。页面内筛选在切换影片页面后重置。
- **演员入口**：汇总已有资料中的演员与影片数量，点击演员可查看相关影片。
- **CSV 导出**：“已整理”和“收藏”可导出当前筛选结果，包含文件名、NFO 标题、分类、演员、NFO 摘要与精彩片段；覆盖全部结果，不限于当前页。
- **索引清理**：“所有数据”可查看缺失、离线、同名影片等记录，批量删除不需要的影库记录，之后可重新扫描导入。

## 来源管理与本地资料

### 导入和扫描

- 支持多个来源，独立命名、启用、禁用与重新扫描；详情页还可只重新扫描当前影片所在目录。
- 可配置递归扫描、忽略目录、视频与图片扩展名，以及启动时自动扫描。
- 默认视频格式包括 MP4、MKV、MOV、AVI、WEBM、M4V、MPG、MPEG、TS、FLV 和 WMV；实际播放能力还取决于视频编码。
- 同目录下按 `名称-cd1.扩展名`、`名称-cd2.扩展名` 等命名的视频作为同一部影片的多个部分；同名但不同扩展名的视频仍作为独立影片。
- 来源离线、扫描失败或取消时保留已有记录。成功扫描后找不到的影片会标为缺失，便于检查。
- 文件改名或移动后，旧路径可能保留为缺失记录，新路径作为新影片导入；可在“所有数据”中清理旧记录。

### NFO、海报、剧照与评论截图

- 读取已有 NFO 中的标题、年份、上映日期、时长、简介、演员、导演、评分、国家、制片公司和标签等资料。
- NFO 标签只读，用于展示和筛选；自己的整理标签使用“我的分类”。
- 可从 NFO 补充空字段，或重新导入时选择合并、替换。应用内编辑内容保存在影库中，不写回 NFO。
- 支持同名海报，如 `MovieA-poster.jpg`；单影片目录还可识别 `poster.jpg`、`folder.jpg`、`cover.jpg`、`fanart.jpg` 等通用资源名。
- 多影片目录中的 `MovieA.jpg` / `MovieA.jpeg` 可作为同名视频海报，同名 `-poster` 图片优先。
- `extrafanart/` 中的图片作为剧照；与其同级的 `comment/` 文件夹中的图片作为精彩评论截图，按自然顺序浏览。
- 图片页显示缩略图，点击打开大图，可用按钮或左右方向键切换。

### 来源转移与删除

- “转移”会实际移动已扫描视频及相关资料到目标来源的独立子目录，保留收藏、分类和精彩片段。
- 转移中断后，下次启动尝试恢复；遇到磁盘离线或文件冲突时，连接相关磁盘并处理提示后再继续。
- 禁用来源保留影片记录；归档来源保留归档记录；删除来源记录或影片索引不会删除外部视频、图片和 NFO。

## 播放与个性化设置

- **详情工作台**：左侧查看资料与分类，右侧播放原片、标注片段和查看图片，画面完整适配、不裁剪。
- **播放选择**：内置播放器播放原片，遇到兼容问题时尝试兼容版本；也可用本地播放器打开视频或定位所在文件夹。
- **字幕**：桌面与网页详情可选择可用字幕轨或关闭字幕，字号可调整。
- **360° VR**：支持单目 360° 视频，按文件保存“是否 VR”设置；拖动转动视角、滚轮缩放，并支持视角复位。共鸣球也可展示 VR 画面。
- **摸鱼模式**：缩小视频和封面画面，视频靠右下、图片居中，外框不变；可选择缩小比例，字幕仍显示在播放器大框底部。
- **启动与托盘**：Windows 正式安装版支持开机自启动、开机仅启动托盘和最小化到托盘；关闭窗口仍会退出应用。
- **缓存管理**：查看播放缓存占用、更改目录和上限、打开缓存文件夹或清理缓存；清理不会删除视频原文件。
- **可选媒体工具**：设置中可配置并测试 ffprobe，配合 ffmpeg 提供更完整的媒体信息、自动封面与兼容播放。未配置时仍可导入影片和读取已有资料。

## 局域网网页访问

设置中开启网页服务，选择仅本机或私有局域网访问，并设置端口与网卡地址。手机、平板或其他电脑可通过显示的地址访问，浏览和筛选影库、查看详情、播放视频、选择字幕和跳转精彩片段。

局域网模式使用与桌面端相同的账号密码，主机应用需要保持运行。网页可查看已有标注，新增标注请在桌面端完成；共鸣球暂未在网页端提供。网页服务面向受信任的私有局域网使用。

## GitHub 私有仓库备份

将影片整理成果备份到自己专用的 GitHub 私有仓库，便于重新安装或换电脑后恢复。

- **备份内容**：收藏、自定义分类关系、精彩片段与共鸣场景，包括临时场景、视频顺序、播放位置、精彩时刻、画面比例和 VR 视角，以及恢复匹配所需的文件信息。
- **媒体保留本地**：不上传原视频、来源路径、盘符、海报、账号凭据或整个本地数据库。
- **备份方式**：手动备份及启动、退出时自动备份；无变化时避免重复上传，失败后下次启动可重试。
- **历史版本**：选择备份版本，先查看可匹配、未找到、同名冲突与可恢复片段的数量。
- **跨电脑匹配**：按文件名、文件大小和可用时长确认本机视频，不要求盘符或目录相同；无法唯一匹配的记录跳过。
- **恢复范围**：覆盖匹配影片的收藏、分类和片段；含场景的备份替换本机全部命名场景与临时场景，无法匹配的场景视频跳过，场景名称与空场景仍保留。
- **恢复保护**：恢复前保存本机整理数据安全副本；空库或影片数量骤减等情况会阻止自动覆盖有效备份。

配置需要专用私有仓库地址，以及该仓库的 Contents 读写权限令牌。旧版不含场景的备份仍可恢复，恢复这类备份时本机场景保持不变。

## 常见问题

**没有 NFO 也能用吗？**

可以导入视频，再自行编辑资料、分类、收藏和标记精彩片段。当前不提供在线影片资料刮削。

**移动硬盘没接上，会丢掉整理数据吗？**

来源离线时保留原有记录，连接磁盘后重新扫描即可检查状态。

**为什么卡片没有视频预览？**

先添加精彩片段并勾选“纳入精彩预览”。没有片段时展示图片；原片不可访问或无法播放时也会回退到图片。

**精彩片段会生成单独的视频文件吗？**

不会，标注用于定位和预览原片，当前不提供片段裁剪导出。

**备份后能直接在新电脑播放吗？**

备份只保存整理数据，需要先把视频放到新电脑可访问的位置并扫描，再恢复备份。

**当前还有哪些边界？**

目前面向 Windows，暂不提供在线刮削、NFO 写回、分类层级、剧集季集管理或自动更新。
